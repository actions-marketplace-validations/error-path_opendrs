# Score saturation: fixPattern and incident granularity on ApacheJIT

Generated by `bench/apachejit/score-saturation-experiment.ts`. Pooled over every project except `apache/hadoop`, on the dataset's official split. Row cache build `08355066ee67`; every signal but `history.prior_fixes`/`history.incident` is the real, shipped value.

## Coverage

- 66653 row-cache commits considered; 0 could not be resolved to a cloned history (kept at their real V0 value in every variant).

## Variants

- **V0 (current).** Shipped `history.fixPattern` and folder-or-file `history.incident` matching.
- **V1 (fixPattern excludes housekeeping scopes).** `^(?!(?:deps?|dependencies|ci|docs?|build|chore|style|tests?)(?:\([^)]*\))?:)(?!\w+\((?:deps?|dependencies|ci|docs?|build|chore|style|tests?)\):)(?!fix:\s*typo\b).*\b(fix(es|ed)?|bug|hotfix|regression|incident|sev\d?|revert)\b`
- **V2 (incident at file level).** Drops the folder-level branch of `history.incident`'s matching.
- **V3.** V1 and V2 together.

## Decision (pre-registration's rule, applied per variant)

- **V1.** Red-share relative reduction 0.9% < 25% threshold; AUC-gain 95% CI 0.0001 to 0.0002 (includes 0 or positive — no significant loss) → **reject**.
- **V2.** Red-share relative reduction 7.4% < 25% threshold; AUC-gain 95% CI 0.0005 to 0.0014 (includes 0 or positive — no significant loss) → **reject**.
- **V3.** Red-share relative reduction 8.3% < 25% threshold; AUC-gain 95% CI 0.0006 to 0.0015 (includes 0 or positive — no significant loss) → **reject**.

## Caveats

- **No rename detection.** The per-commit file lists come from `git log --name-only --no-renames` (not the shipped detector's `-M`), so a rename shows as a delete and an add rather than one path; both the current commit's own changed files and the historical file-touch index use the same raw paths. This understates `history.prior_fixes`'s true lookback count and can miss a file-level `history.incident` match across a rename, in both V0's reproduction and every other variant equally.
- **Unresolved rows keep their real V0 value.** 0 of 66653 row-cache commits could not be matched to the cloned history by sha (a shallow fallback mismatch, or a sha the clone does not have); those rows never vary across V0–V3, which understates each variant's effect rather than overstating it.
- **The decision rule's AUC side accepts a CI that excludes 0 in the negative direction as a loss, not a wash** — consistent with the change-coupling experiment's reading of the same kind of rule.
- **ApacheJIT is Java and mostly pre-dates Conventional Commits**, hence the separate, descriptive field-repo count on vite/black/cli, which do use that convention.
